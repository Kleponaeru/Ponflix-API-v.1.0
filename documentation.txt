# Ponflix API

This project exposes a small JSON API backed by AniWatch (`https://aniwatchtv.ro`).

## Provider layout

The AniWatch scraper lives in `src/lib/providers/aniwatch/`:

- `client.ts` and `api.ts` handle AniWatch page and API requests.
- `parser/` converts AniWatch HTML and JSON into the app's response shapes.
- `latest.ts`, `spotlight.ts`, `trending.ts`, `search.ts`, `anime.ts`, `episodes.ts`, and `episode.ts` provide the data operations used by routes.

## Public routes

- `GET /api/spotlight` — current spotlight items.
- `GET /api/trending` — trending anime.
- `GET /api/latest` — latest completed anime.
- `GET /api/latest-completed` — alias for the latest completed feed.
- `GET /api/search?q=<query>` — search AniWatch.
- `GET /api/anime/<slug>` — anime details.
- `GET /api/anime/<slug>/episodes` — episode list.
- `GET /api/episode/<id>` — episode playback metadata and sources.

The home page at `/` contains the request and response examples for these routes. Examples are copied as API paths so they work with any host.

## Development

```bash
npm run dev
npm run build
```

The API uses `ANIWATCH_BASE_URL` from `src/constants/index.ts` as the single provider base URL.
