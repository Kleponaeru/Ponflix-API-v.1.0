# Ponflix API

This project exposes a small JSON API backed by AniWatch (`https://aniwatchtv.ro`).

## Provider layout

The AniWatch scraper lives in `src/lib/providers/aniwatch/`:

- `client.ts` and `api.ts` handle AniWatch page and API requests.
- `parser/` converts AniWatch HTML and JSON into the app's response shapes.
- `latest.ts`, `spotlight.ts`, `trending.ts`, `search.ts`, `anime.ts`, `episodes.ts`, and `episode.ts` provide the data operations used by routes.

## Public routes

- `GET /api/spotlight` — current spotlight items.
- `GET /api/trending` — trending anime.
- `GET /api/latest` — latest completed anime.
- `GET /api/latest-completed` — alias for the latest completed feed.
- `GET /api/search?q=<query>` — search AniWatch.
- `GET /api/anime/<slug>` — anime details.
- `GET /api/anime/<slug>/episodes` — episode list.
- `GET /api/episode/<id>` — episode playback metadata and sources.

The home page at `/` contains the request and response examples for these routes. Examples are copied as API paths so they work with any host.

## LK21 routes

- `GET /api/lk21/latest` — latest films from the full movie list.
- `GET /api/lk21/latest-movies` — latest movies widget from the home page.
- `GET /api/lk21/top-series` — featured series widget from the home page.
- `GET /api/lk21/search?q=<query>&page=<page>` — search movies and series.

- `GET /api/lk21/<type>/<slug>` - movie or series details and embedded player options; `<type>` is `movie` or `series`.

LK21 routes and types are kept separate from AniWatch. The detail route returns the source's public embed URLs; it does not extract or proxy the underlying video stream.

## TMDB routes

- `GET /api/tmdb/search?query=<query>&page=<page>&language=<language>` — search TMDB movies.
- `GET /api/tmdb/movie/<id>?append_to_response=videos,images` — TMDB movie details, with optional appended subrequests.
- `GET /api/tmdb/v3/discover/movie?...` — filtered movie discovery; TMDB's supported filters are passed through.
- `GET /api/tmdb/v3/trending/movie/<day|week>` and `/api/tmdb/v3/movie/<popular|now_playing|upcoming|top_rated>` — browse movie feeds.
- `GET /api/tmdb/v3/genre/movie/list` — movie genres.
- `GET /api/tmdb/v3/movie/<id>/<resource>` — public movie resources such as `credits`, `videos`, `images`, `recommendations`, `similar`, `release_dates`, `external_ids`, and `watch/providers`.
- `GET /api/tmdb/v3/watch/providers/movie` — list movie streaming providers.
- `GET /api/tmdb/v3/configuration` — TMDB image configuration.

The read-only `/api/tmdb/v3/` proxy also supports TMDB movie/person search, collections, IMDb-ID lookup, and people details with movie credits. It forwards public query parameters and keeps TMDB credentials server-side. Watch-provider availability is powered by JustWatch and requires JustWatch attribution in the app.

Set `TMDB_READ_ACCESS_TOKEN` (recommended) or `TMDB_API_KEY` in the server environment. Movie detail requests forward `append_to_response`, `language`, and `include_image_language` to TMDB.

## Development

```bash
npm run dev
npm run build
```

The API uses `ANIWATCH_BASE_URL` from `src/constants/index.ts` as the single provider base URL.
